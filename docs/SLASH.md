# Слэш-команды, навыки и цикл /loop

В поле ввода чата набери `/` — появится список. Всё, что ниже, лежит **обычными файлами в проекте**: их можно коммитить, и вся команда (и любые агенты) получит то же самое.

## Встроенные команды

| Команда | Что делает |
| --- | --- |
| `/loop [x5] [каждые 10m] задача` | Агент сам повторяет задачу проход за проходом. См. ниже |
| `/match [97%] [x20] [файл.html]` | Приложи скриншот-эталон: агент подгоняет вёрстку, пока страница не совпадёт. См. ниже |
| `/autopilot [баги тесты визуал …] [каждые 10m]` | Агент сам придумывает улучшения и делает их, пока не нажмёшь «Стоп». См. ниже |
| `/audit [область]` | Аудит проекта, отчёт в `docs/AUDIT.md`, код не меняется |
| `/stop` | Остановить агента, цикл и очистить очередь сообщений |
| `/clear` | Чистый контекст: модель перестаёт видеть переписку до этой отметки (на экране она остаётся) |
| `/memory текст` | Записать решение в общую память проекта |
| `/plan задача` | Только план, без правок |
| `/review` | Ревью текущего `git diff` |
| `/test [что]` | Написать тесты и прогнать |
| `/explain вопрос` | Объяснить код, ничего не меняя |
| `/init` | Создать `AGENTS.md` проекта |
| `/skills`, `/skill имя …`, `/help`, `/model` | Список навыков, применить навык, справка, выбор модели |

## /loop — «делай, пока не готово»

```
/loop разбери все TODO в коде            пока агент сам не скажет «готово»
/loop x5 улучши покрытие тестами          максимум 5 проходов
/loop каждые 10m проверь статус сборки    пауза между проходами (s, m, h; минимум 2 с)
/loop ∞ …                                 то же, что без числа
```

Каждый проход — обычный ход агента (карточки правок, команды, права уровня автономности — всё как всегда). Цикл останавливается, когда:

- агент написал отдельной строкой `LOOP_DONE` (цель достигнута или нужен человек);
- набран лимит проходов (`x5`, максимум 500);
- три одинаковых ответа подряд (агент ходит по кругу);
- ошибка модели или кончился месячный лимит расходов;
- ты нажал «Стоп цикла» / `/stop`, закрыл проект.

Состояние цикла живёт в памяти приложения: после перезапуска цикл не продолжается. Если во время паузы ты сам написал агенту, цикл дождётся конца твоего хода. **Без лимита расходов платная модель может потратить много** — задай лимит в «Расходы».

## /match — «сделай как на скриншоте»

1. Приложи скриншот (скрепка или вставка из буфера) — это эталон.
2. Напиши `/match`. Необязательно: `97%` (нужное сходство, по умолчанию 96%), `x20` (максимум проходов), `index.html` или `http://localhost:5173/` (какую страницу снимать; по умолчанию `index.html` проекта).

Каждый проход приложение **настоящим браузером** (Edge/Chrome на этом компьютере) снимает страницу в размере эталона, считает долю совпавших пикселей и показывает агенту три картинки: эталон, текущий вид и карту различий (красным — что не совпало), плюс названия самых «красных» областей. Агент правит вёрстку и всё повторяется. Цикл останавливается, когда сходство достигло цели, когда прогресс замер на несколько проходов подряд или когда ты нажмёшь «Стоп». Эталон нельзя вставлять картинкой — агент предупреждён.

Нужны: модель с поддержкой изображений (иначе агент увидит только цифры и названия областей), Edge или Chrome, локальный сервер TetraFree. Другой браузер — путь в переменной окружения `TF_BROWSER`. Пиксель-в-пиксель на живых данных (даты, аватары, анимации) не получится — цель 96–98% обычно и есть «выглядит одинаково».

## /autopilot — «сам придумывай, что улучшить»

Агент по кругу берёт направления: баги → тесты → безопасность → рефакторинг → визуал → удобство → скорость → документация → идеи → инструкции и команды проекта. Можно сузить: `/autopilot баги тесты`, добавить паузу `каждые 10m` и пожелания: `/autopilot визуал только страница входа`.

Каждый проход агент оценивает проект, выбирает 1–3 самых ценных улучшения, делает, проверяет командами проекта и **записывает в `.tetra/autopilot.md`** что сделал, какие есть идеи и проблемы — это его память между проходами и перезапусками. Каждая правка — отдельная версия проекта, её можно откатить. Агент умеет смотреть в интернет (`<search>`, `<fetch>`) и на собственный результат (`<shot>`). Работает бесконечно: останавливает только «Стоп», ошибка модели, лимит расходов или три одинаковых ответа подряд. Включай на уровне «Уведомить» — на «Спросить»/«Эскалация» правки будут ждать тебя.

## Интернет и скриншоты у агента

Во всех ходах агент может написать `<search>запрос</search>`, `<fetch url="https://…" />` и `<shot path="index.html" />`. Читает локальный сервер: наружу только http(s), адреса внутренней сети, localhost и служебные блокируются (проверяется IP соединения, включая редиректы); страница до 2 МБ, в ответ идёт текст до 30 тыс. символов. Всё прочитанное помечено для модели как недоверенные данные. Поиск — через html.duckduckgo.com без ключей; если его формат изменится, `<search>` перестанет работать, а `<fetch>` — нет.

## Свои команды

Файл `.tetra/commands/<имя>.md` (также читаются `.claude/commands/` и `.opencode/command/` — команды из Claude Code и OpenCode работают как есть). Вложенные папки дают имя через двоеточие: `git/pr.md` → `/git:pr`.

```md
---
description: Починить баг по описанию
argument-hint: <что сломано>
---
Найди причину бага: $ARGUMENTS
Сначала воспроизведи (запусти тесты), потом исправь минимально и прогони тесты снова.
```

`$ARGUMENTS` — всё после имени команды, `$1`…`$9` — отдельные слова (в кавычках — одно слово). Нет плейсхолдера — аргументы дописываются в конец. Имена встроенных команд занять нельзя.

## Навыки

Папка `.tetra/skills/<имя>/` (также `.claude/skills/`, `.agents/skills/`) с файлом `SKILL.md` — формат [Agent Skills](https://agentskills.io), как у Claude Code:

```md
---
name: pdf
description: Работа с PDF — извлечь текст, склеить, разрезать. Применять, когда в задаче есть .pdf
---
1. Для текста используй `pdftotext -layout файл.pdf -`.
2. …
```

- Агент **видит список навыков (имя + описание)** в каждом ходе и сам читает `SKILL.md`, когда задача подходит. Поэтому описание пиши как «когда применять».
- `/имя-навыка задача` или `/skill имя задача` — применить явно: инструкция подставляется в запрос целиком.
- Рядом с `SKILL.md` можно положить скрипты и справочники — агент читает их через `<read>`.
