# Автоматизации

«Когда случилось X — сделай Y». Файл `.tetra/automations.json` лежит в проекте и едет вместе с ним. Управление: «Настройки → Автоматизации» или `/auto`.

```json
{
  "automations": [
    {
      "name": "Утренняя сводка",
      "when": { "daily": "09:00" },
      "do": { "agent": "Сделай сводку изменений за вчера" }
    },
    {
      "name": "Тесты при правках",
      "when": { "files": "src/*.ts" },
      "do": { "agent": "Запусти тесты: {{files}}", "tier": "Уведомить" }
    },
    { "name": "Готово!", "when": { "task": "done" }, "do": { "notify": "Закрыта задача: {{task}}" } }
  ]
}
```

## Когда (`when`, одно из)

| Поле     | Смысл                                                                                                      |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| `every`  | Раз в N: `"30m"`, `"2h"`, не чаще раза в минуту                                                            |
| `daily`  | Каждый день в `"ЧЧ:ММ"`; если приложение было закрыто в это время — окно 1 час, догонять не будем          |
| `files`  | Файлы изменились (маска или список масок; папка `.tetra/` игнорируется). Срабатывает через 8 секунд тишины |
| `task`   | Задача перешла в статус `backlog`, `doing`, `review` или `done`                                            |
| `open`   | Проект открыт                                                                                              |
| `manual` | Только кнопкой «Запустить сейчас»                                                                          |

## Что (`do`, одно из)

- `agent` — запрос агенту. Создаётся чат «⚙ имя». `tier` — уровень свободы (по умолчанию «Спросить»: правки и команды ждут вашего решения).
- `notify` — уведомление.
- `task` — создать задачу.

В тексте работают `{{files}} {{task}} {{name}} {{project}} {{now}}`.

## Безопасность

- Автоматизация не запустится, пока вы не нажмёте «Разрешить…». Разрешение привязано к хэшу содержимого: изменили файл — разрешение сбросилось. Файл из чужого репозитория сам ничего не сделает.
- Не больше 20 срабатываний в час на проект; автоматизация не запускается повторно, пока предыдущий запуск идёт.
- Агент-автоматизации тратят токены. На уровнях «Тихо» и «Уведомить» агент меняет файлы и запускает команды без вопросов — давайте их только доверенным файлам.

## Ограничения

Работает только пока TetraFree открыт и проект выбран. После перезапуска время последнего запуска помнится, но пропущенное не догоняется.

## Управление фоном в 3.2

В заголовке рабочего проекта доступны «Пауза автоматизаций» и «Остановить всё». Пауза запрещает новые автоматические запуски. Общая остановка также прерывает агентов, циклы, пайплайны и отложенную очередь; расписание не снимает паузу само. Новый явный ручной чат остаётся доступен.

История хранит до 100 запусков глобально, в окне показываются последние 30 выбранного проекта. После перезапуска running становится interrupted; автоматического продолжения нет. Повтор требует подтверждения и использует текущую конфигурацию/approval, не старый промпт или контекст файлового события. В истории нет исходников, запросов, ключей или URL провайдера.

`costLimit` и `monthlyLimit` в конфигурации — положительные USD-лимиты на запуск/месяц для автоматизации. Изменение требует нового approval. Перед каждым model request добавляется консервативный резерв входа и 16 000 output tokens. Неизвестный тариф при настроенном лимите блокирует запрос. Без лимита стоимость может остаться неизвестной. Резервы не возвращаются после отмены; global budget учитывает существующую оценку месяца плюс резервы, поэтому возможна ранняя остановка. Это локальный admission control, не гарантия биллинга провайдера и не межпроцессный spending lock.

Фон работает только пока приложение живо и выбран проект. С треем окно можно скрыть после сохранения; полный выход останавливает работу. Службы для закрытого приложения нет. Уведомления автоматизаций требуют отдельного opt-in и общего системного разрешения; Windows может подавить доставку. Текст уведомления обезличен.
