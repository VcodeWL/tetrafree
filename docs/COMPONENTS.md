# Библиотека компонентов

Режим «Дизайн» → кнопка «Библиотека компонентов» в левой панели (или команда `/components`).

**Источники.** shadcn/ui, Magic UI, React Bits — публичные реестры в формате shadcn; плюс «Свой реестр»: ссылка на `registry.json` (список) или на `компонент.json` (один элемент).

**Что можно сделать с компонентом**
- **Смотреть вживую.** TSX компилируется в браузере (Babel), пакеты берутся с esm.sh, стили — Tailwind v4. Если у реестра есть пример (`…-demo`), показывается он, иначе компонент получает текст «Привет, TetraFree» в `text` и `children`. Анимации работают.
- **Вставить на страницу.** В HTML-страницу дизайна добавляется блок `<div data-tf-ui>` со скриптом-загрузчиком. На холсте это рамка-заглушка (холст не запускает скрипты), живой компонент виден на вкладке «Превью» и в опубликованной странице. Стили Tailwind действуют только внутри блока и не меняют остальную страницу. Нужен интернет у посетителя страницы.
- **Добавить в проект.** Это правильный путь для настоящего React-проекта: файлы раскладываются в `src/components/ui`, `src/lib` (или рядом с уже существующими папками), импорты переписываются в относительные, `cn` берётся из вашего `lib/utils` или создаётся, недостающие пакеты дописываются в `package.json` (версии спрашиваются у npm; после этого выполните `npm install`), стили (`@keyframes`, `@theme`) дописываются в CSS с Tailwind, если он есть. Существующие отличающиеся файлы заменяются только после явного подтверждения; откат — в истории версий.

**Ограничения.** Предпросмотр зависит от esm.sh, jsdelivr и реестров; без сети не работает. Компоненты, которым нужны особые props или контекст, в предпросмотре могут показать ошибку или пустое место — это не значит, что они сломаны. Если на странице уже подключён Tailwind CDN v3, возможны конфликты стилей. Реестры, которые отдают только список без содержимого файлов, не поддерживаются.
