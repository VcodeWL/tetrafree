# TetraFree 3.1.4 — аудит интерфейса и редакторов

> Результаты и ограничения проверки приведены в разделе ниже; audit не означает применение исправлений.

Дата: 2026-10-13. Код приложения не изменялся. Проверено на Chromium/Linux через настоящий dev UI; Design дополнительно через рендер тех же React-компонентов с контролируемыми callbacks. Результаты повторного прогона — `ui-results.json`, `ui-run.log`. Использованы только отдельный тестовый профиль и искусственные проекты.

## Подтвержденные сценарии

### UI-01 · P1 — смена проекта перезаписывает одноимённый файл даже без редактирования

`src/workspace/RightPane.tsx:1069–1075`, `src/workspace/CodeEditor.tsx:145–184`.

У A и B `README.md` содержит CONTENT_A и CONTENT_B. Переключение без размонтирования Workspace, в том числе из палитры (`src/modals/Palette.tsx:191,374`), сохраняет экземпляр CodeSurface: key включает только file, не pid. Content-эффект принимает B, но flush-эффект использует старый textRef и новый p.id. Итог реального UI-теста: A=CONTENT_A, **B=CONTENT_A**, в просмотре ещё видно CONTENT_B. Ввод текста не требуется.

Исправление: идентичность редактора `{pid,file}`, сохранение только собственных dirty-правок; регрессии смены проекта через палитру и создания нового проекта из workspace.

### UI-02 · P1 — удалённый файл воскресает из pending autosave

`src/workspace/CodeEditor.tsx:145–152,181,186–190`; `src/store/slices/files.ts:47–66`.

Ввести UNSAVED_TYPED и удалить открытый файл до debounce 220 мс. После deleteFile файл отсутствует, после размонтирования — снова существует с UNSAVED_TYPED. Cleanup flush вызывает writeFile, который создаёт путь без проверки поколения/удаления. Достижимо при удалении агентом/внешней синхронизацией во время ввода. Переименование старого пути — соседняя гипотеза, отдельно не считалось подтверждённым.

Исправление: compare-before-save и file generation; при delete/rename отменять либо переносить pending правку.

### UI-03 · P1 — Design сохраняет страницу B через callback страницы A

`src/design/CodeEditor.tsx:42–51`; `src/design/Studio.tsx:337–342`.

Cleanup с пустым deps захватывает первоначальные value/onChange. При смене страницы экземпляр не получает новый key. Показать A, затем B, набрать B_TYPED и размонтировать раньше 350 мс: **callback A получает B_TYPED**. Studio пишет без явного pid, усиливая межпроектный риск.

Исправление: scoped editor `{pid,path}`, актуальные refs, flush именно исходного документа.

### UI-04 · P1 — смена Design-страницы с pending таймером дополнительно перезаписывает A содержимым B

`src/design/CodeEditor.tsx:29–51`; `src/design/Studio.tsx:337–342`.

Набрать A_TYPED, перейти в B до 350 мс, затем закрыть редактор. Выполняются сохранения `[a,A_TYPED]`, затем **`[a,B_ORIGINAL]`**. Таймер при смене path/value не отменён, typed.current становится B; cleanup сравнивает с первоначальным A.

Это второй сценарий того же корневого lifecycle-дефекта UI-03, **не дополнительный независимый баг**. Оба сценария нужны в регрессиях.

### UI-05 · P2 — валидация пути пропускает регистронезависимого файл-родителя

`src/lib/paths.ts:20–26`.

`checkPath({files:{Foo:'file'},dirs:[]},'foo/bar.txt')` возвращает null. Полная коллизия проверяется без регистра, предки — регистрозависимо. На обычной Windows FS Foo — файл, создать в нём директорию нельзя. Функция проверена; Windows API не исполнялся.

Исправление: единая нормализация для предков/потомков, файлов/папок и case-only rename.

### UI-06 · P3 — Esc не заканчивает редактирование, вопреки подсказке

`src/workspace/CodeEditor.tsx:212–214`; `src/workspace/RightPane.tsx:986,1085–1086`.

После Escape textarea остаётся, снимается только фокус. editing не меняется. Исправление: onFinish в родителе либо честная подсказка.

### UI-07 · P2 — сочетания редактора не работают в русской раскладке

`src/workspace/CodeEditor.tsx:206,216`; `src/App.tsx:158–159`.

App использует code, а локальный редактор key. Событие code=Slash, key='.', Ctrl не предотвращено, комментарий не добавлен. Проверено на поддерживаемом Markdown. Ctrl+S с key='ы' следует тому же неверному условию, но отдельное физическое Windows-нажатие не проверено. Автосохранение продолжает работать.

Исправление: использовать code последовательно; регрессии русской/латинской раскладки.

### UI-08 · P2 — сложный RegExp блокирует основной поток поиска

`src/lib/replace.ts:21–25,43–56`; `src/modals/Replace.tsx:26–38`.

findHits выполняется синхронно в useMemo, без временного бюджета. Отдельная проверка маленького текста с backtracking-регуляркой не завершилась за 5 секунд (timeout exit 124). Лимит 1 МБ не предотвращает проблему на очень коротких строках. Это проверка чистой функции; намеренного зависания общего браузера не делалось.

Исправление: отменяемый Worker с тайм-аутом либо безопасный движок регулярных выражений.
