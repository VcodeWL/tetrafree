# 3.4.0 — Фон под контролем

Новый центр фоновых операций собирает существующую работу в одном read-only представлении. Открытие окна ничего не запускает; отмена и повтор остаются явными действиями с проверкой исходного проекта и живого runtime.

## Что изменено

- Общий список ходов агентов, повторов команд, очередей, циклов, пайплайнов, синхронизации, ожидающих правок и автоматизаций.
- Фильтры «Сейчас / Требует внимания / История / Все», область проекта и локальный поиск.
- Точная отмена текущего runtime без очистки очереди; отдельное подтверждение для destructive clear и повторов автоматизации.
- Честные состояния `stopping` и orphaned persisted `running`: запрос отмены и отсутствие живого исполнителя не выдаются за завершение или успех.
- Ограниченная по объёму проекция без полного сканирования длинной истории каждую секунду.
